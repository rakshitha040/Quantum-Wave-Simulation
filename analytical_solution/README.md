# Analytical Solution of the 1D Wave Equation

This module provides analytical reference solutions for the one-dimensional wave equation. The analytical solutions are used as reference solutions for validating the numerical and quantum approaches developed in the main research project.

The analytical results provide a benchmark for evaluating the accuracy of the numerical finite difference solution and the quantum Hamiltonian simulation.

---

## 1. Governing Equation

The one-dimensional wave equation is:

∂²u/∂t² = c² ∂²u/∂x²

where:

- u(x,t) is the wave displacement
- c is the wave propagation speed
- x is the spatial coordinate
- t is time

The analytical solution depends on the initial displacement, initial velocity, and boundary conditions imposed on the problem.

---

## 2. Purpose of the Analytical Solution

The analytical solution serves as a reference or benchmark solution for the other computational approaches.

The main purposes are:

- Validate the numerical finite difference solution
- Evaluate numerical discretization error
- Provide a reference for quantum Hamiltonian simulation
- Compare wave evolution obtained using different approaches
- Support convergence and accuracy analysis

The analytical solution is therefore treated as the reference against which computational solutions are evaluated.

---

## 3. Analytical Solution Approach

For the one-dimensional wave equation with fixed boundary conditions, the solution can be represented using a Fourier sine-series expansion.

For a domain of length L, the solution can be expressed as:

u(x,t) = Σₙ [Aₙ cos(ωₙt) + Bₙ sin(ωₙt)] sin(nπx/L)

where:

- Aₙ and Bₙ are coefficients determined from the initial conditions
- n is the spatial mode number
- L is the length of the spatial domain
- ωₙ = cnπ/L is the angular frequency of the nth mode

The coefficients are determined from the prescribed initial displacement and initial velocity.

---

## 4. Initial Conditions

The implementation considers the initial conditions corresponding to the wave cases studied in the main project.

The analytical reference solution is evaluated on the same spatial grid used by the computational solvers so that the solutions can be compared directly.

Using the same spatial grid ensures that differences between the solutions are primarily associated with the numerical or quantum approximation rather than differences in spatial sampling.

---

## 5. Spatial Grid

The analytical solution uses the same spatial-grid convention as the numerical implementation.

For a domain of length L with Nx spatial points:

Δx = L / (Nx - 1)

The spatial coordinates are:

x = 0, Δx, 2Δx, ..., L

The implementation uses an odd number of spatial grid points so that the midpoint:

x = L/2

lies exactly on a grid point.

This allows direct comparison of the midpoint displacement between the analytical and computational solutions.

## 9. Validation of Numerical Solution

The analytical solution is used as the reference solution for validating the numerical finite difference method.

The numerical and analytical solutions can be compared at corresponding spatial and temporal grid points.

A common measure used for this comparison is the Root Mean Square (RMS) error.

The RMS error is calculated from the difference between the reference and computational solutions.

A decreasing error with increasing spatial resolution indicates convergence of the numerical solution toward the analytical reference.
