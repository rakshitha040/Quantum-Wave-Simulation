# Quantum Wave Simulation

A research project focused on comparing **classical numerical methods** and **quantum Hamiltonian simulation** for solving the **One-Dimensional Wave Equation**.

---

## Research Title

**Classical vs. Quantum: A Comparative Study of Finite Difference and Hamiltonian Simulation Approaches to the 1D Wave Equation**

---

## Project Overview

This project investigates two different computational approaches for solving the one-dimensional wave equation:

- **Classical Solver**
  - Finite Difference Method (FDM)
  - Leapfrog Time Integration

- **Quantum Solver (Upcoming)**
  - Hamiltonian Formulation
  - Quantum Time Evolution
  - Quantum Circuit Simulation

The objective is to compare both methods in terms of formulation, implementation, and simulation.
